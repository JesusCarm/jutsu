# Internationalization

The application defaults to English. `?lang=es` selects the Spanish sample dictionary; `?lang=en`, an absent parameter, or an unsupported language selects English. The header flags update the Angular Router URL without reloading, preserving other query parameters and the fragment. Back and Forward use the same state. Language is not stored in cookies or browser storage.

## Files and responsibilities

| File | Purpose |
| --- | --- |
| `public/i18n/en.json` | Complete English reference for keys, UI copy, and game text. |
| `public/i18n/es.json` | Same structure with a few sample translations; `null` means use English. |
| `src/app/core/i18n/i18n-keys.ts` | Generated category constants and recursive `TranslationKey` union. |
| `src/app/core/i18n/i18n.service.ts` | Singleton Signals state, async loading/cache, URL synchronization, and initialization. |
| `src/app/core/i18n/translation-dictionary.ts` | Immutable dictionary snapshot, interpolation, and active/English/key fallback. |
| `src/app/core/i18n/game-text.ts` | Angular-independent game presentation and localized PDF DTO. |
| `src/app/core/i18n/game-text.service.ts` | Reactive Angular access to game text. |
| `src/app/core/i18n/languages.ts` | Supported language metadata for the header and URL validation. |
| `src/assets/data/` | Stable IDs, stats, structured costs, flags, and numeric rule parameters. |

`NinjaLabels` has been removed. Types, schools, techniques, weapons, and items all use the dictionaries. Selection values are IDs such as `physical`, `protectiveGate`, or `smokeBomb`; translated labels never identify a selection. Changing language does not publish a new squad revision or recreate form controls. Free-form squad and ninja names are preserved.

## Editing text

Use typed constants in components and services:

```ts
i18n.t(Stats.attack);
i18n.t(Actions.download);
i18n.t(Labels.ninja, { number: 1 });
i18n.t(Techniques.protectiveGate.description, { successes: 1, maxChakra: 5 });
```

Game components should use `GameTextService` for the final example so that parameters come from the catalog, rather than duplicating numeric rules in the caller. Descriptions interpolate placeholders such as `{attackDice}`, `{dieSides}`, and `{range}`. References to Kunai or Smoke Bomb use their translated names too. Text costs are formatted from numeric data: an amount, a range, a maintenance cost, or an action count.

Add or change the English source, then run:

```bash
npm run i18n:generate
npm run i18n:check
```

The generator validates nonempty English leaves, catalog ID coverage, locale keys, and interpolation tokens. It creates nested `as const` objects (`App`, `Stats`, `Actions`, `Labels`, `Messages`, `NinjaTypes`, `TechniqueGroups`, `Techniques`, `Weapons`, `Items`, and cost/short-stat categories). The union derives from their leaf values. Arbitrary translation keys fail TypeScript checking. The generated file is versioned for IDE completion.

Development and build scripts regenerate keys. Type checking and tests check for stale generated files. Adding translations to existing keys does not change components or generated constants. Missing, `null`, or empty translations fall back per key to English, and a missing English value falls back to the key.

To add another locale, add its JSON file, register its ID/label/icon in `LANGUAGES`, and register its decorative flag in `UiIconComponent`. Existing components and translation constants need no manual changes. If adding a new language-button label, add that English key and regenerate constants. New locale files may be partial. The Spanish dictionary is intentionally incomplete pending review; do not expand it into a full translation in this phase.

## Loading and deployment

`app.config.ts` awaits `I18nService.initialize()` through `provideAppInitializer` before rendering dependent components. English loads first, then the URL-selected locale. `PlatformAssetsService.publicUrl()` resolves `i18n/{lang}.json` against `document.baseURI`, so deployment under `/games/jutsu/` requests `/games/jutsu/i18n/en.json`, rather than the domain root. Publish the `i18n/` directory alongside the built application and set the correct `<base href>`.

At runtime a language request updates the language revision, uses English while loading, and ignores late responses superseded by another navigation. The PDF generate buttons are disabled while loading. A failed optional locale shows an English fallback notice and can be retried; a failed English reference stops initialization with a readable bootstrap error. Dictionaries are cached in memory only.

## PDF boundary

`PdfGenerationService` captures a `GameText` snapshot and converts the squad to `LocalizedBandSnapshot` before calling the existing pure engine. The DTO keeps the original PDF paths (`techniqueGroup.name`, technique `name`/`description`, inventory `name`, and formatted `chakra`) while the editable domain uses IDs and structured costs. No Angular services enter the engine.

Language changes invalidate saved bytes and pending generations, even if the original language is selected again. Squad edits and template changes retain the same protection. The filename remains `jutsu-squad-[name].pdf`, or `jutsu-squad.pdf` without a name.

`PdfTemplateOption.labelKey` translates the selector label. Its optional `localized` factory map selects a locale-specific design, falling back to the shared `create` factory. Only the current shared template is registered. PDF artwork, coordinates, icons, and fonts are unchanged. The current design prints technique names/descriptions and equipment names; it has no field for ninja type or equipment descriptions. Those are localized in the DTO for templates that choose to print them.

## Verification

Run `npm run typecheck`, `npm test`, and `npm run build`. Tests cover URL defaults, direct Spanish access, subpath URLs, asynchronous startup/cache/races/failures, Back/Forward, query and fragment preservation, fallback, interpolation, form identity and data preservation, localized PDF fields, and language-based stale-result rejection. A frozen pre-migration catalog verifies every English rule, cost, stat, and Mokushin flag. The earlier coordinate-rendering reference remains unchanged.

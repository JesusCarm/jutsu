## Shadow Techniques

<a id="jutsu-vinculo-sombrio"></a>

### Shadow Bind

**Chakra:** 3 · **Timing:** Action · **Range:** LoS, up to 8″.

Immobilize an enemy. To move, it must spend an action and pass a 1D6 roll against the user’s Skill; each attempt costs an action. The user cannot perform actions involving movement. If either unit moves, the bind ends.

<a id="jutsu-transporte"></a>

### Transport

**Chakra:** 3 · **Timing:** Action/Mokushin · **Range:** LoS, up to 6″.

Teleport to a visible point, passing through terrain and enemies, without spending Movement or triggering a Charge.

<a id="jutsu-sombra-ramificada"></a>

### Branching Shadow

**Chakra:** 5 · **Timing:** Action · **Range:** Up to 8″.

Make two separate 4D6 ranged attacks against the same target or two different targets.

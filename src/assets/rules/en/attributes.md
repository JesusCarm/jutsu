### ![Attack](assets/icons/ataque_ico.svg) Attack

Number of D6 rolled when attacking.

<a id="defense-stat"></a>

### ![Defense](assets/icons/defensa_ico.svg) Defense

Number of D6 rolled when defending.

<a id="skill"></a>

### ![Skill](assets/icons/habilidad_ico.svg) Skill

Minimum result required for a success. In combat, use the opponent’s Skill.

<a id="movement-stat"></a>

### ![Movement](assets/icons/movimiento_ico.svg) Movement

Number of inches available during a Movement action.

<a id="chakra"></a>

### ![Chakra](assets/icons/chakra_ico.svg) Chakra

Energy used for Jutsus and special manoeuvres.

<a id="life"></a>

### ![Health](assets/icons/vida_ico.svg) Health

Starts at 10. Each hit removes 1 Health (unless stated otherwise). At 0, remove the unit.
